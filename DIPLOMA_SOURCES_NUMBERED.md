# Список источников (нумерованный, для ссылок по тексту)

Ниже дан шаблон нумерации для корректного цитирования в тексте ВКР.

1. Microsoft Learn. ASP.NET Core documentation. URL: https://learn.microsoft.com/aspnet/core
2. Salesforce CRM. Официальная документация и материалы. URL: https://www.salesforce.com
3. Bitrix24. Описание платформы и возможностей CRM. URL: https://www.bitrix24.ru
4. amoCRM. Описание возможностей системы. URL: https://www.amocrm.ru
5. Onfleet. Last-mile delivery management platform. URL: https://onfleet.com
6. Bringg. Delivery management and orchestration platform. URL: https://www.bringg.com
7. NIST/ISO материалы по secure software development и управлению рисками.
8. Kotler P., Keller K. Marketing Management (разделы по ценообразованию и эластичности спроса).
9. PostgreSQL Documentation. URL: https://www.postgresql.org/docs
10. Entity Framework Core Documentation. URL: https://learn.microsoft.com/ef/core
11. SignalR Documentation. URL: https://learn.microsoft.com/aspnet/core/signalr
12. Confluent Kafka Documentation. URL: https://docs.confluent.io
13. Azure Blob Storage Documentation. URL: https://learn.microsoft.com/azure/storage/blobs
14. Stripe / YooKassa API docs (по фактически используемому провайдеру).
15. Flutter Documentation. URL: https://docs.flutter.dev
16. Blazor Documentation. URL: https://learn.microsoft.com/aspnet/core/blazor

## Пример оформления ссылок в тексте

- "Серверная часть реализована на ASP.NET Core [1]."
- "Хранение данных реализовано в PostgreSQL с ORM EF Core [9], [10]."
- "Realtime-коммуникации реализованы через SignalR [11]."
- "Мобильный клиент может быть реализован на Flutter [15]."

## Важно для финальной редакции

1. Проверить, чтобы каждая ссылка `[N]` в тексте имела запись в списке источников.
2. Проверить, чтобы источники, на которые нет ссылок в тексте, были удалены.
3. Выдержать единый формат библиографического описания (ГОСТ/требование учебной части).
