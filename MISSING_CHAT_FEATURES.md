# Недостающий функционал чата

## 🔴 Критически важные функции

### 1. **Отметка всех сообщений как прочитанных**
- **Проблема:** Сейчас можно отметить только одно сообщение
- **Нужно:** `MarkAllMessagesAsRead(chatRoomId, userId)`
- **Использование:** Когда пользователь открывает чат, все сообщения должны стать прочитанными

### 2. **Уведомления о новых сообщениях**
- **Проблема:** Нет интеграции с NotificationService
- **Нужно:** При отправке сообщения создавать уведомление для участников, которые не в сети
- **Использование:** Пользователь получает push-уведомление о новом сообщении

### 3. **Статусы доставки сообщений**
- **Проблема:** Нет статусов "отправлено/доставлено/прочитано"
- **Нужно:** Добавить поле `DeliveryStatus` в ChatMessage
- **Использование:** Пользователь видит, доставлено ли сообщение и прочитано ли

### 4. **Управление участниками чата**
- **Проблема:** Нет методов для получения/добавления/удаления участников
- **Нужно:** 
  - `GetParticipants(chatRoomId)`
  - `AddParticipant(chatRoomId, userId)`
  - `RemoveParticipant(chatRoomId, userId)`
- **Использование:** Менеджер может добавить участника в чат по заказу

### 5. **Права доступа и модерация**
- **Проблема:** Нет проверки прав, менеджеры не могут удалять чужие сообщения
- **Нужно:** 
  - Проверка ролей перед отправкой
  - Менеджеры могут удалять любые сообщения
  - Менеджеры могут добавлять участников
- **Использование:** Модерация конфликтов, управление чатом

## 🟡 Важные функции

### 6. **Поиск по сообщениям**
- **Нужно:** `SearchMessages(chatRoomId, searchText)`
- **Использование:** Поиск информации в истории чата

### 7. **Упоминания пользователей (@mentions)**
- **Нужно:** 
  - Парсинг @username в сообщениях
  - Уведомления для упомянутых пользователей
  - Поле `MentionedUserIds` в ChatMessage
- **Использование:** Привлечение внимания конкретного участника

### 8. **Ответы на сообщения (Reply/Quote)**
- **Нужно:** 
  - Поле `ReplyToMessageId` в ChatMessage
  - Отображение исходного сообщения при ответе
- **Использование:** Ответ на конкретное сообщение в потоке

### 9. **Реакции на сообщения (эмодзи)**
- **Нужно:** 
  - Таблица `MessageReactions` (MessageId, UserId, Emoji)
  - Методы добавления/удаления реакций
- **Использование:** Быстрая обратная связь без текста

### 10. **Закрепление сообщений**
- **Нужно:** 
  - Поле `IsPinned` в ChatMessage
  - Метод `PinMessage(messageId)`
  - Метод `GetPinnedMessages(chatRoomId)`
- **Использование:** Закрепление важной информации (адрес доставки, инструкции)

## 🟢 Дополнительные функции

### 11. **Архивирование чатов**
- **Нужно:** Поле `IsArchived` в ChatParticipant
- **Использование:** Скрытие завершенных чатов

### 12. **Пересылка сообщений**
- **Нужно:** Метод `ForwardMessage(messageId, targetChatRoomId)`
- **Использование:** Пересылка информации в другой чат

### 13. **История изменений сообщений**
- **Нужно:** Таблица `MessageEditHistory` для отслеживания изменений
- **Использование:** Аудит, прозрачность

### 14. **Валидация и ограничения**
- **Нужно:** 
  - Проверка максимальной длины сообщения (5000 символов)
  - Rate limiting (защита от спама)
  - Валидация attachmentUrl
- **Использование:** Защита от злоупотреблений

### 15. **Метаданные сообщений**
- **Нужно:** 
  - IP адрес отправителя (для аудита)
  - Устройство/платформа
  - Версия клиента
- **Использование:** Отладка, безопасность

### 16. **Групповые операции**
- **Нужно:** 
  - Отметить все как прочитанное во всех чатах
  - Получить общее количество непрочитанных
- **Использование:** Удобство для пользователя

### 17. **Статистика чата**
- **Нужно:** 
  - Количество сообщений в чате
  - Последняя активность
  - Самый активный участник
- **Использование:** Аналитика
