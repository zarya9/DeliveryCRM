# Приложение: формы отчетов по DeliveryCRM

Документ подготовлен как приложение к ВКР для закрытия замечания "нет форм отчетов".

## Форма Ф-1: Свод по заказам за период

**Назначение:** оценка общего операционного результата за выбранный период.

**Поля формы:**
- Период (дата начала, дата окончания)
- Количество заказов (всего)
- Количество доставленных
- Количество отмененных
- Доля доставленных, %
- Доля отмен, %
- Среднее время доставки, ч
- Выручка, руб.

## Форма Ф-2: Популярность услуг и рекомендации по цене

**Назначение:** анализ спроса и подготовка предложений по корректировке цены.

**Поля формы:**
- Услуга / тип заказа
- Количество продаж
- Выручка
- Средняя маржинальность, %
- Доля просрочек SLA, %
- Индекс популярности
- Рекомендация (повысить/оставить/снизить)
- Комментарий аналитика

## Форма Ф-3: SLA-отчет по зонам

**Назначение:** контроль качества доставки по геозонам.

**Поля формы:**
- Зона
- Количество заказов
- Среднее время доставки, ч
- Доля просрочек SLA, %
- Количество критических инцидентов
- Ответственный логист
- Рекомендованное действие

## Форма Ф-4: Эффективность курьеров

**Назначение:** контроль производительности и качества работы курьерского контура.

**Поля формы:**
- Курьер
- Количество назначений
- Количество доставок
- Среднее время доставки
- Доля просрочек, %
- Средняя оценка/рейтинг
- Количество возвратов/проблемных кейсов

## Форма Ф-5: Клиентский и CRM-отчет

**Назначение:** оценка активности клиентских сегментов.

**Поля формы:**
- Сегмент клиента
- Активных клиентов
- Новых клиентов за период
- Повторные заказы
- Доля повторных заказов, %
- Churn-risk (низкий/средний/высокий)
- Рекомендации по коммуникации

## Форма Ф-6: Финансовый отчет по тарифам

**Назначение:** сравнение финансовой эффективности тарифных планов и услуг.

**Поля формы:**
- Тариф / услуга
- Количество заказов
- Выручка
- Себестоимость
- Валовая маржа
- Доля отмен
- Доля просрочек SLA
- Рекомендация по тарифу
