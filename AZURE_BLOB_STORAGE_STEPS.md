# Пошаговая интеграция Azure Blob Storage

## 📋 Шаг 1: Создание Azure Storage Account

1. Войдите в [Azure Portal](https://portal.azure.com)
2. Нажмите **"Создать ресурс"** → найдите **"Storage account"**
3. Заполните форму:
   - **Подписка**: выберите вашу подписку
   - **Группа ресурсов**: создайте новую или выберите существующую
   - **Имя учетной записи хранения**: например `deliverycrmstorage` (должно быть уникальным)
   - **Регион**: выберите ближайший (например, West Europe)
   - **Производительность**: Standard
   - **Избыточность**: LRS (локально избыточное хранилище) - для разработки
4. Нажмите **"Просмотр и создание"** → **"Создать"**
5. Дождитесь создания (1-2 минуты)

## 📋 Шаг 2: Получение Connection String

1. Откройте созданный Storage Account
2. В меню слева выберите **"Ключи доступа"** (Access keys)
3. Скопируйте **"Строка подключения"** (Connection string) из **key1**
   - Формат: `DefaultEndpointsProtocol=https;AccountName=...;AccountKey=...;EndpointSuffix=core.windows.net`

## 📋 Шаг 3: Установка NuGet пакетов

Выполните в терминале (в папке проекта):
```bash
dotnet add package Azure.Storage.Blobs
```

## 📋 Шаг 4: Настройка appsettings.json

Добавьте в `appsettings.json`:
```json
{
  "AzureStorage": {
    "ConnectionString": "ваш-connection-string-здесь",
    "ContainerName": "deliverycrm"
  }
}
```

## 📋 Шаг 5: Создание контейнера в Azure

Контейнер будет создан автоматически при первом запуске, но можно создать вручную:

1. В Azure Portal откройте ваш Storage Account
2. Выберите **"Контейнеры"** (Containers)
3. Нажмите **"+ Контейнер"**
4. Имя: `deliverycrm`
5. Уровень публичного доступа: **"Blob (анонимный доступ только к BLOB-объектам)"**
6. Нажмите **"Создать"**

## 📋 Шаг 6: Тестирование

После реализации кода:
1. Запустите API
2. Откройте Swagger UI
3. Загрузите аватар через `/api/Files/avatar`
4. Проверьте в Azure Portal, что файл появился в контейнере
