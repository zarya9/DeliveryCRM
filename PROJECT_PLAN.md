## Тема дипломного проекта

**«Разработка CRM‑системы для управления курьерской службой доставки с модулем гео‑аналитики и оптимизации маршрутов»**

## Основные подсистемы (что уже есть и что доработать)

1. **Управление сотрудниками и ролями** ✅ (базовый функционал реализован)
   - Роли: Клиент, Менеджер, Логист, Курьер, Администратор.
   - Сотрудники привязаны к компании (`Company_id`), менеджер видит только своих.
   - Страница «Сотрудники компании» для менеджера:
     - список сотрудников (ФИО, роль, email, статус, дата создания);
     - поиск по ФИО;
     - индикатор «онлайн/оффлайн», пометка текущего пользователя «(Вы)»;
     - карточка сотрудника (модальное окно с аватаром, контактами и кнопкой «Написать»);
     - создание новых сотрудников с выбором роли.

2. **Управление клиентами** ✅ (карточка и история реализованы)
   - Карточка клиента:
   - контакты (телефон, email);
   - история заказов;
   - заметки менеджера, жалобы и отзывы;
   - статус клиента / сегмент (активный, проблемный, VIP и т.п.).

3. **Лиды и воронка продаж**
   - Лиды (потенциальные клиенты) ✅ API и модели:
   - источник (сайт, звонок, рекомендация и т.д.);
   - ответственный менеджер;
   - стадия (новый, в работе, договор, отказ).
   - Воронка продаж:
   - визуальное представление стадий;
   - конверсия из лида в клиента и в заказ;
   - отчёты по менеджерам.

4. **Заказы и логистика**
   - Создание и управление заказами (статусы, типы доставок).
   - Привязка заказов к клиентам и курьерам.
   - **Тип маршрута заказа** (`DeliveryRouteKind`): город / через склады (хабы) / прямой межгород; при создании заказа генерируется **упорядоченный массив точек** `OrderRouteStops` (остановки; переезды — между соседними точками).
   - **Склады (хабы)** компании: API `GET/POST /api/LogisticsHubs`, страница логиста `/logistician/hubs`.
   - Распределение заказов логистом:
     - учёт расстояния, загрузки курьеров, рейтинга.
   - Мониторинг заказов для менеджера и логиста.

5. **Гео‑аналитика и маршруты**
   - Карта с курьерами и заказами (Leaflet + OSM).
   - Маршруты курьеров:
     - визуализация текущих и исторических маршрутов;
     - интеграция с движком маршрутизации (OSRM/другой сервис) для реальных маршрутов по улицам.
   - Гео‑аналитика:
     - «горячие зоны» заказов;
     - среднее время доставки и % опозданий по районам.

6. **Задачи и коммуникации**
   - Задачи по клиенту и заказу:
     - «перезвонить», «подтвердить адрес», «подтвердить оплату» и т.д.;
     - сроки, ответственный, статус выполнения.
   - Чат (SignalR):
     - общий корпоративный чат;
     - чаты по заказам/клиентам;
     - интеграция с уведомлениями (toast + push).

7. **Финансы и отчёты**
   - Учёт статуса оплаты заказа.
   - Отчёты:
     - выручка по периодам, по клиентам, по курьерам;
     - средний чек;
     - эффективность менеджеров (лиды → заказы).

8. **Администрирование и настройки компании**
   - Настройки компании:
     - реквизиты, логотип, тарифы, рабочие часы.
   - Управление ролями и правами:
     - доступ к разделам по ролям;
     - возможность включать/отключать модули.
